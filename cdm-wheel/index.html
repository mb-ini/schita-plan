About this page

One product, five standards, and where they disagree

Banks trade hundreds of kinds of financial products, and every system that touches one describes it in its own way. Five international standards try to bring order, and they do not agree with each other. This page takes the 17 foreign-exchange (FX) derivative products that the official registry knows about and shows, product by product, what each standard says about it, and where it says nothing.

Why it matters

The same product, described in five languages

An FX forward or an FX option passes through a bank’s trading system, its risk engine, its regulatory reporting and the market-data feeds it buys. Each of them names and structures the product differently, and every connection between two systems ends up with its own hand-made translation, which can be wrong in its own way. A canonical model is a single internal vocabulary with explicit, checkable translations to each outside standard. Before building one, you need to see how far apart the standards really are. That is what this page is for.

UPI · ANNA-DSB

ISO 4914

The official identity of an over-the-counter derivative, used in regulatory reporting. A strict tree: asset class, instrument type, product.

CFI

ISO 10962

A six-character classification code. Each position answers its own question, so it is a set of facets, not a tree.

CDM

ISDA / FINOS

A common model of trades. It does not list product types; it decides them with rules that read the trade’s terms.

FpML

XML for derivatives

The format banks use to confirm derivative trades with each other. A product is a composition of building blocks.

FIBO

EDM Council

An ontology of financial terms. A class can have several parents, so it does not fit into any single tree.

Because the five have different shapes (a tree, a code, a rule set, a composition, an ontology), no single hierarchy is true for all of them at once. So the page does not impose one. It fixes the list of products and lets each standard say what it says about each of them.

How to read it

Two views of the same 17 products

Lanes: the comparison table

One row per product, grouped into forwards, options and swaps; one column per standard. Each cell shows what that standard calls the product. Hover a row to follow it across all five standards; click it to pin it and read the details on the right.

Wheel: the overview

The 17 products sit on the rim and never move. The inner rings show how one standard groups them; switch between UPI, CFI and CDM with the buttons above the wheel. Where a ring breaks into repeated pieces, that standard groups the products in a different order: the break is the disagreement.

The panel on the right

Pick a product to see how each standard describes it, and where it has nothing to say. Every line cites the file it was read from in the project’s copy of the standards, so any claim can be checked.

Below the views

Headline numbers (for example how many of the 17 products have a CDM rule) and a list of the places where the standards do not line up, each with its sources.

On a screen narrower than about 1000 pixels the two diagrams would become unreadable, so the page shows a list of the 17 products instead, with the same detail.

How the links were made

Every claim points to a file and a line

Each standard was downloaded into the project and kept unchanged. Every value on this page was read from those copies, and every link between a product and a standard cites the exact file and line it rests on. A checking program opens every citation each time the page is built: in this version, 5,410 checks over 224 citations. A citation that nobody opens is decoration.

Not every link is equally strong, so each one is labelled. These are the colours used in the Lanes view:

  • exactthe standard says the same thing, confirmed against the cited line
  • evidenced-namethe two names are made of the same words
  • editoriala judgement call, with a citation and a written reason
  • broaderthe standard’s term is true but says less than the product
  • absentthe standard could have answered and does not

Honest note on this version. In this first snapshot the links were written by hand, each with its citation. Later the same morning they were replaced by links derived automatically from the standards’ own files, because hundreds of hand-written links cannot each be checked, and a plausible-looking invented reference passes review.

  4. 4

    The whole landscape (not on this page)

    The list grew to 169 products: every over-the-counter template the registry publishes plus 59 groups of listed and cash instruments. Limits

What not to rely on

  • This is a research prototype, not a product. Nobody outside the automated process has yet reviewed the results against known trades.
  • Only the 17 FX templates of the registry are covered here, at the registry’s coarse granularity.
  • The CFI descriptions come from a public secondary source (iotafinance.com), cross-checked against Wikipedia where possible. ISO 10962 itself is a paid standard and is not included.
  • The FpML schemas used are version 5.14, a working draft, not a final recommendation.
  • In this version the links between products and standards were written by hand (see above).
Glossary

The terms, briefly

OTC
Over the counter: a contract agreed directly between two parties, not on an exchange.
FX forward
An agreement to exchange two currencies at a fixed rate on a future date.
NDF
Non-deliverable forward: a forward settled in cash, in one currency, for currencies that cannot be freely delivered.
FX option
The right, not the obligation, to exchange currencies at an agreed rate.
FX swap
Two currency exchanges in opposite directions on two dates.
UPI / ANNA-DSB
The Unique Product Identifier for OTC derivatives (ISO 4914), issued by the ANNA Derivatives Service Bureau from product templates.
CFI
Classification of Financial Instruments (ISO 10962): a six-character code.
FpML
Financial products Markup Language: the XML format for derivative trade confirmations.
CDM
Common Domain Model: ISDA’s shared model of trades and their life-cycle events.
FIBO
Financial Industry Business Ontology from the EDM Council: formal definitions of financial terms.
Canonical model
An organisation’s single internal vocabulary, with explicit translations to each outside format.
